## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

数据库自增主键在分库之后就不适用了，我们需要一个能生成有序且全局唯一 ID 的组件。请从零实现它，仓库目前只有一个空的 Maven 工程（pom.xml 只有 JUnit 5 与 AssertJ）。要求：1) 采用雪花（Snowflake）风格的 ID 结构，由时间戳、工作节点标识与序列号组成；需在 README 中画出位分配表并说明各段的位数与容量上限；2) 有序性：同一节点生成的 ID 必须严格递增，需提供多线程测试验证并发下无重复且单调递增；3) 时钟回拨：必须检测系统时钟回拨，并按回拨幅度选择策略——小幅回拨等待追平，大幅回拨抛出明确异常；两种情况都要有可注入时钟的测试覆盖；4) 工作节点标识分配：提供 SPI 与一个内存实现（用于测试），并说明生产中如何替换为数据库或注册中心实现；5) 批量取号：支持一次获取一批 ID 以减少竞争，批量模式下整体仍需单调递增；6) 解析工具：提供把 ID 反解为时间戳、节点标识与序列号的方法，并验证与生成结果一致；7) `mvn -q verify` 跑通，覆盖并发唯一性、单调递增、时钟回拨两条分支、批量取号、反解一致性；8) README 说明位分配、回拨策略与单节点容量等已知限制。
